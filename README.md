# profile-site

개인 프로필 & 링크 페이지 (link in bio).

인스타그램, 블로그 등 흩어져 있는 링크를 한 페이지에 모아두는 사이트입니다.
모바일에서 보기 좋은 것을 우선으로 합니다.

## 상태

초기 설정 단계. 아직 페이지 내용은 없습니다.

## 계획

- [ ] 내용 정하기 (이름, 소개, 링크 목록)
- [ ] 페이지 제작 (모바일 우선)
- [ ] GitHub Pages 배포
- [ ] 커스텀 도메인 연결

## 구조

아직 정해지지 않았습니다. 단일 HTML 파일로 시작할 예정입니다.
