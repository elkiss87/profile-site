# 도메인과 DNS

`elkiss.me` 를 고르고 산 근거, 그리고 GitHub Pages에 연결할 때 알아야 하는 개념.
실제 연결 절차는 [DEPLOY.md](DEPLOY.md) 에 있다.

---

## 1. 도메인이 하는 일

브라우저든 프로그램이든 **결국 IP로 접속한다.** 소켓은 이름을 모른다.
사람이 IP를 외울 수 없으니 이름을 IP로 바꿔주는 층이 필요하고, 그게 DNS다.

**도메인을 산다는 것은 "이 이름을 조회하면 내 IP가 나오도록" 등록하는 것**이다.

### 소유가 아니라 임대다

도메인은 **연 단위 사용권**이다. 갱신하지 않으면 권리가 사라지고,
유예기간이 지나면 다른 사람이 등록할 수 있다.

**자동 갱신을 반드시 켜둔다.** 만료된 개인 도메인이 넘어가는 것은 흔한 사고다.

---

## 2. 이름은 오른쪽이 상위다

```
        www  .  elkiss  .  me  .
         │       │        │    │
         │       │        │    └─ 루트 (보통 생략)
         │       │        └────── TLD
         │       └─────────────── 등록하는 부분
         └─────────────────────── 서브도메인 (제한 없이 생성 가능)
```

파일 경로와 반대 방향이다.

**돈을 내고 사는 것은 `elkiss.me` 하나뿐이고, 그 아래 서브도메인은 무제한 무료다.**

```
elkiss.me          ← 구매 대상
├─ www.elkiss.me   ← 무료
├─ blog.elkiss.me  ← 무료
└─ 임의.elkiss.me   ← 무료
```

### .me 에 대해

몬테네그로 국가 도메인(ccTLD)이다. 등록 제한이 없고 영어로 "나"를 뜻해서
개인 사이트에 관행적으로 쓰인다. 국적·거주지 요건이 없다.

**다만 .com 보다 갱신비가 비싸다.** 연 $15~20 선.

---

## 3. DNS는 분산 위임 구조다

서버 한 대가 전체를 아는 것이 아니라, 계층적으로 위임되어 있다.

```
[리졸버] "www.elkiss.me 어디야?"
   │
   ├─→ [루트]        ".me 담당자를 알려줄게"
   ├─→ [.me]         "elkiss.me 담당 네임서버를 알려줄게"
   └─→ [Cloudflare]  "185.199.108.153"      ← 우리가 설정하는 지점
```

**아무도 전체를 모르고, 각자 다음 담당자만 안다.**

도메인을 사서 하는 일은 세 번째 화살표에 "Cloudflare에게 물어보라"고 등록하는 것이다.
그 아래는 전부 우리가 통제한다.

---

## 4. 등장인물 셋

| 누구 | 역할 |
|---|---|
| **레지스트리** | TLD 전체의 원장 관리. TLD당 하나 |
| **레지스트라** | 판매 대리점. Cloudflare, Porkbun 등 |
| **네임서버** | 실제로 질의에 답하는 서버 |

**레지스트라는 판매 창구일 뿐이고, 어디서 사든 등록되는 원장은 같다.**
비싼 곳에서 산다고 도메인이 좋아지지 않는다. 차이는 가격, DNS 기능, UI 뿐이다.

---

## 5. 레코드 종류

| 타입 | 뜻 |
|---|---|
| **A** | 이름 → IPv4 |
| **AAAA** | 이름 → IPv6 |
| **CNAME** | 이름 → **다른 이름** (별칭) |
| NS | 이 구역 담당 네임서버 |
| SOA | 구역 시작점 정보 |

**A 와 CNAME 의 차이가 중요하다.**

- **A** — IP를 직접 지정한다. 그 IP가 바뀌면 직접 고쳐야 한다
- **CNAME** — 다른 이름으로 넘긴다. 넘긴 쪽 IP가 바뀌면 자동으로 따라간다

GitHub Pages는 IP를 변경할 수 있다. **그래서 CNAME이 안전하다.**

## 6. apex 문제 ★

**apex(루트)** 는 앞에 아무것도 붙지 않은 도메인이다.

| 이름 | 종류 | CNAME |
|---|---|---|
| `elkiss.me` | apex | ❌ 불가 |
| `www.elkiss.me` | 서브도메인 | ✅ 가능 |

### 왜 안 되나

CNAME의 정의가 **"이 이름에 대한 모든 것을 저쪽에서 가져와라"** 이기 때문이다.
필드 하나를 가리키는 것이 아니라 이름 전체를 대체한다.
그래서 **CNAME이 있는 이름에는 다른 레코드가 함께 있을 수 없다.**

그런데 apex는 **NS와 SOA를 반드시 가져야 한다.** 없으면 위임이 성립하지 않는다.

```
apex에 CNAME을 걸면  → 다른 레코드가 있으면 안 됨
그런데 apex는        → NS, SOA가 반드시 있어야 함
                     → 동시에 성립 불가
```

서브도메인은 NS/SOA가 필요 없어서 CNAME이 자유롭다.

### 그래서 원래는

apex에는 A 레코드로 IP를 직접 지정해야 한다.
**GitHub이 IP를 바꾸면 사이트가 조용히 죽는다.**

---

## 7. CNAME flattening

Cloudflare는 이 문제를 이렇게 우회한다.

설정 화면에서는 apex에 CNAME을 거는 것처럼 보이지만, 실제 질의가 들어오면
**Cloudflare가 대신 대상을 조회해서 나온 IP를 A 레코드로 응답한다.**

```
[방문자]      "elkiss.me 어디야?"
    ↓
[Cloudflare]  (내부적으로 elkiss87.github.io 조회)
    ↓
[방문자]      "A: 185.199.108.153"    ← CNAME 아님. 표준 위반 없음
```

**GitHub이 IP를 바꿔도 자동으로 따라간다.**

다른 업체는 **ALIAS** 또는 **ANAME** 이라고 부른다. 표준이 아니라 업체별 기능이라
이름이 제각각이다.

> `nslookup elkiss.me` 결과가 CNAME이 아니라 IP로 나오는 것이 이 기능이 동작한 증거다.
> `www` 는 CNAME 그대로 나오고 루트만 IP로 나온다.

**이것이 Cloudflare를 고른 실질적인 이유다.**

## 8. TTL과 전파

레코드마다 **TTL**(초)이 붙는다. **캐시 유효기간**이다.

리졸버가 한 번 조회하면 TTL 동안 다시 묻지 않고 캐시된 답을 준다.
전 세계 리졸버가 각자 캐시를 들고 있고 만료 시점이 제각각이다.

**"DNS 전파"는 무언가가 퍼져나가는 것이 아니라, 각자 캐시가 만료되기를 기다리는 것이다.**
무효화 브로드캐스트가 없고 TTL 만료가 유일한 갱신 수단이다.

- 신규 등록: 보통 몇 분 ~ 1시간
- 최대: 24~48시간
- 확인은 시크릿 창, 또는 다른 네트워크(폰 LTE)에서

> **주의:** 안 될 때 "전파 중이겠지" 하고 기다리는 것이 가장 흔한 함정이다.
> 조회부터 해서 레코드가 실제로 존재하는지 확인한다. 자세한 내용은
> [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 9. 레지스트라 선택 (2026-07 조사 기록)

| 레지스트라 | 등록(1년) | 갱신(연) | 메모 |
|---|---|---|---|
| **Cloudflare Registrar** | $16.56 | $16.56 | 원가 판매. DNS 포함. WHOIS 프라이버시 무료 |
| Porkbun | 저가 | 등록가와 동일 | ALIAS 지원. WHOIS 프라이버시 무료 |
| Dynadot | $9.56 | $17.53 | 첫해 싸고 갱신에서 회수 |
| Namecheap | 할인 | 인상됨 | 첫해 할인 후 갱신가 상승 |
| GoDaddy 류 | 매우 쌈 | 매우 비쌈 | 업셀 많음. 비추천 |

**첫해 가격이 아니라 갱신 가격을 보고 골라야 한다.**
첫해 $2 미끼에 2년차 $30을 받는 곳이 많다.

### 결정: Cloudflare Registrar

1. **apex에 CNAME을 걸 수 있다** (CNAME flattening) — 실질적으로 이것 때문이다
2. 원가 판매 — 등록가와 갱신가가 같다
3. DNS가 같이 온다 — 한 화면에서 끝난다
4. WHOIS 프라이버시 무료

단점은 무료 계정 가입이 필요하고 Cloudflare DNS를 써야 한다는 것. 문제가 되지 않았다.

### 구매 시 확인할 것

- [ ] 검색창에서 실제 가용 여부 확인 (DNS 조회는 확정 근거가 아니다)
- [ ] **갱신 가격** 확인
- [ ] WHOIS 프라이버시 포함 여부 — 없으면 주소·전화번호가 공개된다
- [ ] 자동 갱신 ON

> **Cloudflare의 플랜 요금표(Free/Pro/Business)는 도메인과 무관하다.**
> 그것은 CDN·방화벽 요금이다. 도메인은 대시보드의 Domain Registration 메뉴에 있고,
> 연 단위로 따로 청구된다. **Free 플랜으로 충분하다.**
