## 2026-07-30

`elkiss.me` 를 GitHub Pages에 연결. 1차 목표 달성.

- 도메인은 Cloudflare Registrar에서 구매. 원가 판매라 갱신 때 가격이 안 뛴다
- `@` 와 `www` 둘 다 CNAME으로 걸고 **DNS only(회색 구름)** 로 둔다.
  프록시를 켜면 GitHub의 도메인 검사가 통과하지 못한다
- HTTPS까지 확인하고 Enforce HTTPS 적용
- DNS 설정에서 세 번 막혔다 → [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
- 문서를 넷으로 쪼갰다. PLAN은 "무엇을", DEPLOY는 "어떻게", DOMAIN은 "왜",
  TROUBLESHOOTING은 "막혔을 때". 한 파일에 다 있으면 실제로 배포할 때 찾기가 어렵다

**배운 것 — DNS는 안 되면 기다리기 전에 조회부터 한다.** 세 번 다 "전파가 늦나" 하고
기다렸는데 실제로는 설정이 빠져 있었다. `nslookup <name> 1.1.1.1` 한 줄이면 갈렸다.

  인스타그램에서 눌러 들어오는 모바일 링크 페이지에는 맞지 않는다
